# AML
Проект по определению вероятности мошенничества для каждой транзакции.

## Основные AML сценарии
1. Structuring - большая сумма дробится на множество небольших операций.
2. Smurfing - большое количество людей переводит небольшие суммы одному получателю.
3. Rapid movement of funds - деньги поступили на счет и почти сразу были переведены дальше.
4. Fan-in - много отправителей переводят одному получателю.
5. Fan-out - один клиент переводит множеству получателей.
6. Circular transactions - деньги перемещаются по цепочке и возвращаются к исходному участнику.
7. Dormant account activation - на ранее неактивном счете внезапно возникает высокая активность.
